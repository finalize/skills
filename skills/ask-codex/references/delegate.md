# 調査・下書き・設計の案を頼む (Claude のトークンを寄せる)

Claude のトークンは、ほぼ「往復の回数 × 会話の長さ」で決まる。2026-11 の synCLO の1セッションでは、要求が 1,599 回、
入力の 99% がキャッシュの読み出し (会話の読み直し) で、料金の重みを付けると全体の約 3/4 だった。
Claude が何十回も grep や cat をする仕事を、Codex の1回と短い報告に置き換えると、往復も会話の長さも減る。

ただし、確かめで見つかるのは間違いで、抜けは見つからない。精査が全部の読み直しになれば、節約は消える。
次の手順は、この2つを防ぐためのもの。

## 頼むもの・残すもの

| Codex に頼む | Claude に残す |
|---|---|
| コードや文書をまたぐ調査、外部の文書の読み込み | ユーザーとのやり取りと判断。設計で何を採るか |
| ログや差分の読み込み | 本番やお客様の環境の操作、外への投稿 |
| 文書の下書きのうち、事実集めと構成 | 最終の文面 (リポジトリの書き方に合わせる) |
| 設計の代案と反論 (反論は `challenge-plan.md`)、テストの下書き | 秘密や実データに近い作業 |

頼んでも得にならないもの: 2〜3回の grep で済む調べもの (頼む文を書く手間のほうが大きい。Codex は中身の無い問いでも、
1回で入力が2〜6万トークンかかる)。会話の経緯を長く書き写さないと伝わらない仕事 (Claude の出力はいちばん高い)。
推論を max のままにすると、Codex 側は重い (2026-11 の ask.sh の差分レビュー1回で、入力 170 万トークン、うちキャッシュ 158 万、
出力 2.8 万、9 分半)。調べものにどの強さが要るかは、まだ比べていない。

## 頼む前に

1. 自分の予想を1〜3行で書いておく (見つかるはずのもの、答えの見当)。Codex には渡さない。報告を読んだ後に、
   報告に引っ張られずに抜けを探すため
2. `-C` は、そのリポジトリにする。リポジトリの `AGENTS.md` が Codex に読まれるのは、`-C` がその中のとき
3. 決めごとは、ファイルの場所を指す。会話の経緯は、決まった結論だけを1行で書く

## 頼み方

`-S schemas/report.json` で報告の形を縛る。長いので標準入力から渡し、`run_in_background` で走らせる。

```
あなたは Claude Code から呼ばれている。質問は返せない。不明な点は仮定を書いて進める。
頼むこと: <調査 / 文書の下書き / 設計の案>
目的: <何に使うか。決めるのはだれか>
範囲: <ファイル、ディレクトリ、コミット、URL>。この外は、要るときだけ読み、読んだら coverage.searched に書く
守ること: リポジトリの AGENTS.md。<この仕事だけの制約>
問い:
1. <絞った問い>
2. ...
主張ごとに、根拠の場所 (`ファイル:行`、打ったコマンド、URL) を付ける。場所を書けない主張は basis を inferred にする。
見ていない範囲は coverage.not_checked に、人が決めることは open_questions に書く。
下書きを頼むときは、本文を draft に入れ、本文の中の事実の主張も findings に1つずつ挙げる。
```

## 精査

- 主張ごとに、根拠の箇所だけを開いて確かめる (`sed -n '<行>p'`、`grep -n`、コマンドを流し直す)。報告の元の資料を
  全部読み直さない
- どこまで確かめるか
  - 決定、お客様や他人に出る文書、コードの変更につながる主張: 全部
  - それ以外: basis が inferred のものと、確信度の低いものから2〜3件。1件でも違っていたら、全部確かめる
- 抜け: 頼む前に書いた予想と、`coverage.searched` を比べる。予想にあって報告に無いものは、自分で1回だけ探す
- `coverage.not_checked` に、読めなかった秘密の置き場が出たら、それで足りているかを判断する。Codex に読ませ直さない
- `open_questions` は Claude が決めない。ユーザーか、決める人に回す
- 下書き: 事実の主張は上と同じに確かめ、文面は Claude がリポジトリの書き方に合わせて直す
- ユーザーへの報告では、Codex の見解と、確かめた事実を分ける

## 測る

- `ask.sh` は、Codex が使ったトークンを標準エラーに1行出し、`${XDG_STATE_HOME:-~/.local/state}/ask-codex/usage.tsv` に足す
- 寄せた効果を見るときは、同じ種類の仕事を、寄せた場合と寄せない場合で比べる。比べるのは、Claude のトークン
  (セッションの記録 `~/.claude/projects/<プロジェクト>/<セッション>.jsonl` の各応答の `usage`)、Codex のトークン、
  精査で見つかった誤りと抜けの数、かかった時間
